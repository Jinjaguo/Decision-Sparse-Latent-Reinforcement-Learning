# EXP3 scripts

- `audit_substrate.py`: T0 read-only provenance and dependency/hash audit.
- `freeze_protocol.py`: writes all outcome-blind preregistration manifests.
- `run_criticality.py`: dry-run, zero-control, and full causal sweep runner.
- `analyze_criticality.py`: frozen aggregation, hierarchical inference, and plots.

All scripts refuse to overwrite an existing run directory.
