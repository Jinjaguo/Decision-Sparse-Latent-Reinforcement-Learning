# Method notes

## Post-EXP11 mainline

Action is the common interface. Contact, motion, outcome and uncertainty specialists evaluate the same candidate chunk; a selector uses only their consequence cards.

## EXP12

Same-state groups explicitly include nominal. Task-native motion targets use audited drawer, stove and bowl semantics. The primary result is that conservative consequence scores can rank pairs and avoid failures, but current candidate sources provide almost no cross-task improvement opportunity. Candidate generation must be solved before coordinator complexity is increased.
