# EXP_R2 — Admissible Pre-Action Feature and Baseline Feasibility Audit

EXP_R2 checks whether the EXP_R1 route-level benchmark has enough decision-time
context for a fair retrieval-only, scalar verifier, and factorized consequence
comparison. It does not fit a model when the required pre-action fields are not
present. Post-action physical progress, force, success, and safety fields remain
labels only.
