# EXP6 — Multi-Radius Convergence and Trust-Region Identification

EXP6 tests whether the corrected-D, finite-radius Panda arm-q response converges below the EXP5 scale. It uses the frozen 30-demo EXP5 cohort, eight outcome-blind branches per demo, four preregistered primary radii and one optional radius admitted only by the pre-outcome numerical-resolution gate.

The experiment estimates radius-resolved response operators, adjacent-radius projector and scale convergence, antithetic asymmetry, held-out prediction, empirical trust regions, and exact named contact-mode divergence. It does not train a scheduler or latent policy.

The controlling protocol is `prompts/EXP6_CODEX_PROMPT_Multi_Radius_Convergence_Trust_Region.md`.
