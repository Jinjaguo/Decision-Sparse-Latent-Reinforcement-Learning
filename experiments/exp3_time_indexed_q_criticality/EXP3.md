# EXP3: Time-Indexed q Criticality

This directory contains the preregistered manifests and configuration for the
third experiment.  EXP3 measures the remaining-horizon physical consequence of
a fixed, small Panda arm-joint perturbation at twelve frozen decision times in
each of nine successful LIBERO demonstrations.

The experiment is intentionally limited to causal time-indexed sensitivity.  It
does not train a latent model, event policy, or reinforcement-learning agent.

Formal execution order:

1. audit the frozen EXP2 substrate;
2. revalidate corrected restore Condition D;
3. freeze all manifests and scientific rules;
4. pass unit tests, dry run, and two-zero-continuation gate;
5. run all 864 interventions;
6. analyze without changing the frozen protocol.
