# EXP9 — Action-Conditioned Hybrid Response Distribution

EXP9 tests whether reusable cross-demonstration structure lives in a probabilistic,
action-conditioned hybrid response model rather than a single explicit local
operator.  Contact changes are outcomes, not exclusion criteria.

The experiment has a strict retrospective Stage A and a conditional confirmatory
Stage B.  Locked EXP8 data are development-only.  A new cohort is forbidden unless
one non-oracle Stage-A model simultaneously passes the frozen risk, response-score,
and uncertainty gates in `configs/stage_a.json`.

No scheduler, controller, MPC, VLA modification, online RL, or latent RL is part of
EXP9.
