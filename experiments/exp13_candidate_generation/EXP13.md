# EXP13 — Task-Aware Multi-Source Candidate Generation

EXP13 tests whether multiple audited proposal mechanisms can create valid action
chunks that outperform the successful nominal continuation often enough for a
coordinator to matter. It compares analytic multi-channel modes, temporal edits,
training-only residuals, cross-demo retrieval, task-progress directions,
predictor-guided proposals, exact gripper timing, and restricted compositions.

Calibration uses episodes 41–42. Development-formal evaluation uses episodes
43–49 with leave-demo-out proposal construction. No coordinator is trained in
this experiment and no online control is performed.
