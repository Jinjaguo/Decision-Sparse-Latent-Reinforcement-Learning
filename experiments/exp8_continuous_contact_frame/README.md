# EXP8 continuous contact-frame response field

This directory contains the outcome-blind frozen protocol for EXP8. The experiment
tests whether continuous surface geometry and action-relative point kinematics make
the preserved-mode H1 response operator reusable across demonstrations.

Formal outcomes must not be inspected until all manifests are frozen, hashed, and
the corrected-D, contact-frame, GPU, and matched-zero gates pass.
