# EXP8 — Continuous Contact-Frame-Conditioned Local Response Field

EXP8 uses a new 30-demonstration cohort: ten qualified, previously unused episodes
per task, selected in ascending episode order. Twelve reference-only boundaries are
frozen per demonstration. Each branch uses the EXP7 radii, seven fit directions,
one held-out direction, and both signs.

The primary population is H1 at the smallest radius when both signs preserve the
exact reference contact mode. The primary endpoint is demonstration-cross-fitted
top-1 subspace similarity. Models, hyperparameters, cross-fit folds, ablations,
risk-threshold selection, and statistical decisions are frozen before formal q
outcomes.

The exact execution and claim boundaries are defined by
`prompts/EXP8_CODEX_PROMPT_Continuous_Contact_Frame_Response_Field.md`.
