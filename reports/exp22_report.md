# EXP22 实验报告：动作后果进展状态机

EXP22 在独立示范中记录动作块的后继状态，以目标后果、阶段推进和局部响应对齐三种方式检索动作，并比较固定路线、停滞状态机、周期多样性和任务特化。校准候选并集完成 24/24，默认失败分支恢复 9/9；冻结主路线为四机制周期循环 `F3_diverse_periodic_cycle`。

正式集 84 个分支、672 次 rollout、47,306 步。主路线 safe success 为 82.14%，默认是 58.33%，提高 23.81 点；需求恢复恰好 60%，安全停止率从 10.71% 降到 9.52%。Drawer/Bowl/Stove 分别完成 22/28、28/28、19/28。Drawer 捕获 80% oracle 空间，但总体 headroom capture 为 68.97%，低于 75%，相当于还差两个安全完成分支，因此 EXP22 判定失败。

F3 与 guarded 前的 F1/F0/E0 路线结果并集分别可达到 71/72/73 个安全完成，全部路线并集为 81/84，说明最后缺口来自可辨识的路线互补和 Stove 接触安全，而不是候选不存在。EXP23 增加首次高力后的撤离、接近阈值的动作缩放、撤离后模式切换和当前状态阶段仲裁，并使用新的 demos 50–56 做确认。
