# Experiment reports

Every completed experiment produces two files in this directory:

1. `exp{id}_report.md` records what was run, all relevant results, failures,
   evidence, reproducibility information, and the allowed scientific conclusion.
2. `next_exp_from{id}.md` proposes the next experiment based on those results,
   including its rationale, hypotheses, controls, metrics, hard gates, expected
   outcomes, fallback methods, and a dated literature scan when useful.

The next-experiment proposal must remain close to the project's research question.
A method pivot is allowed only when the current method is technically invalid or
cannot answer the question, and the report must state exactly what changes and what
scientific claim remains comparable.
